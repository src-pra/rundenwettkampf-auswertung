Farben

Für die Auswertung der Rundenwettkämpfe reicht Punkt 1. Punkt 2 und 3 sind freiwillig und zeigen auf dem TV-Wartebild, wer gerade an welchem Stand schießt.

1. DISAG-Datenbank (nötig für die Auswertung)
Die Datenbank von OpticScore, meist C:\Disag\Daten\dboss.mdb. Gelesen wird nur eine Kopie, OpticScore wird nicht gestört.
2. DISAG JSON Live (freiwillig: Schützen und Schüsse live auf dem Wartebild) Vorher in OpticScore einschalten: im OpticScore-Server unter Extras › Optionen › JSON Live JSON Live aktivieren. Für „UDP-Port“ den dort eingestellten Port übernehmen (Standard 30169). Für „Logdatei“ dort zusätzlich „Ausgabe in Logfile aktivieren“ anhaken und hier die Datei wählen.
Datenquelle der Schüsse
Das Programm liest nur mit. Schützen erscheinen ab dem ersten Schuss. UDP kennt nur Schüsse seit Programmstart, die Logdatei alle von heute.
3. Zuweisung sofort anzeigen (freiwillig, baut auf Punkt 2 auf) Schützen erscheinen schon beim Zuweisen in OpticScore, nicht erst beim ersten Schuss. Dafür stellt der Knopf das Log-Level von OpticScore von ERROR auf INFO um.
Stand-Protokoll: wird geprüft …
Wirkt sofort. Danach OpticScore neu starten. Anderer PC: dort „Stand-Protokoll einschalten.reg“ ausführen. Achtung: Mit Log-Level INFO schreibt OpticScore deutlich mehr Logs (jede Nachricht an jeden Stand). Das braucht Speicherplatz und kann theoretisch zu Problemen führen. Bei Nichtgebrauch wieder ausschalten.
Leer = automatisch. Der Ordner liegt neben der dboss.mdb, meist C:\Disag\Daten\RangesLog. Gelesen werden so viele Stände wie bei „Anzahl Stände“.
